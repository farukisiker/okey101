## fakeTypes.ts (app) ile farklar — B5 entegrasyonu eşler
- `turn`: `number` → `number | null` (el bitince null).
- Motor üretmez, host ekler: `players[].totalScore`, `connected`, `isBot`; `turnMsLeft`, `noticeMsLeft`, `notices`; `result.totals`, `winnerSeats`, `matchOver`.
- `result`: motorda `{ scores }`. `declarerSeat` = `view.declarer`, `contractBid` = `view.contract`, `declarerSucceeded` = `tricksWon[declarer] >= contract`.
- Ek alanlar: `options`, `dealer`, `turnNumber`, `declarer`, `contract`, `forcedBid`, `lastTrick`, `tricks`, `lastAction`, `players[].isDeclarer`.
- `minBid` = ayar değeri (BidDialog zaten `b > highestBid && b >= minBid` hesaplıyor). `canPass` ihale boyunca hep true.
- `players[].bid`: null = konuşmadı, 0 = hiç ihale vermeden pas, n = son ihalesi (sonra pas geçtiyse `passed: true` ile birlikte n kalır).
